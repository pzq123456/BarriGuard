# BarriGuard 水马缺口检测 —— 传统 CV 自主缺口检测算法报告

日期：2026-09-04　相机：1749（1920x1080 RTSP）　代码：`water_barrier/research/`
（`segment.py` 分割基座 + `detect.py` 缺口检测 + `run.py` 实验入口）

> 说明：本报告描述**不依赖"缺口位置"预标记**的自主检测方案。第一版"硬编码 GAP 框
> + 局部覆盖率"只能验证已知位置，已被废弃；本文不含任何缺口坐标先验。

## 1. 目标

用**传统 CV（无深度学习）** 从水马隔离带中自主找出缺口，且**事先不知道缺口在哪**。
难点不在检测逻辑，而在分割：实流白天光照会把明亮路面/树影误判为水马前景，生成假的
"墙"，导致大量虚报；而真缺口常因**人/车把一条线切断成几块**、恰好落在连通块边界而被
漏报。本方案围绕这两点做了针对性设计。

## 2. 流程

```
图像/RTSP ──> 分割基座(红底座锚定 + 最大/次大连通域稳定化) ──> 自主缺口检测(inter + intra) ──> 缺口框
```

只用了"隔离带大致存在 + 水马尺寸尺度"两个粗先验，**无缺口位置假设**。

## 3. 分割基座（`segment.py`）

1. **红底座锚定**：红色（H 红 + S + a\*）几乎不出现在路面/灰车/树影，是最稳信号。先检
   出红底座，再用**连通域相交**保留"与红底座同属一个水马单元的白板"——既能收进近景大
   尺寸白板（其红底座在正下方远处），又能丢弃与之无连接的孤立白色（高亮路面、白车、
   天空、货车）。
2. **近严远宽**：远端带色相/S 不稳，放宽阈值，但仍以红底座锚定。
3. **形态学**：开去噪 + 闭运算 + 沿路向线段核，把红白堆叠抹平成连续屏障带。
4. **连通域稳定化（最大 + 次大思想）**：只保留面积前 `TOP_CC=3` 的大连通块并做红/白色
   检，丢弃零星噪声块。这既让"墙"干净，也让"缺口把一条线切成两三个大块"这一现象可被
   检测器利用。

## 4. 自主缺口检测（`detect.py`）

"墙"被缺口切断成几块，因此缺口分两类：

- **块间断口 `inter`**：把大块按水平顺序排，相邻两块若**纵向重叠较大**（同一水马线）且
  横向开口落在 `[min_gap, max_gap]` 内 → 报为移除缺口；开口 `> max_gap`（默认 min×3）视为
  行边界/场景尺度，忽略以防误报。
- **块内缺口 `intra`**：每个大块内逐列量"带覆盖率"（带高**随透视自动收缩**，远处被拉瘦
  的水马不会被误判为低覆盖），覆盖率 `< thr` 的内部连续段即缺口。

缺口的 x/y 包围框由图像推导（两块之间中点 / 低覆盖段范围），非手工标。

## 5. 实验结果

每帧输出结果附可视化（`python research/run.py`）：绿 = 分割掩膜，红框 = 检出缺口。

| 帧 | 分割前景px | 检出缺口 | 判定 |
|----|-----------|----------|------|
| day_1333 (1623x909) | 323.5k | inter (689,545,747,603) sev=0.91 | **命中真缺口**（人站立的缝） |
| day_0944 (1622x905) | 335.1k | inter (688,534,748,594) sev=0.92；intra (1118,329,1142,389) sev=0.66 | 命中真缺口 + 远端一处候选 |
| 实流 17:58 (1920x1080) | 181.3k | inter (808,632,890,714) sev=1.00；intra (192,687,232,833) sev=0.46 | **命中真移除缺口**（人被切断处）+ 近端一处候选 |

- 两帧标注帧真缺口都在 x≈[685,748]，即画面中有人站在那里的缝隙；算法在**没有缺口坐标**
  前提下唯一/精确地把它框出。
- 实流上那个真缺口是在旧方案里"人把墙切断、落到连通块边界"而**漏报**的那个，现在被
  `inter` 块间断口稳定命中（severity=1.00）。
- 其余候选（远端植被/近端局部遮挡）属单帧边界情形，帧间位置稳定，不再出现旧方案每帧

## 6. 局限性（诚实版）

| 环节 | 结论 |
|------|------|
| 单帧语义 | 无法区分"人/车/遮挡"与"真移除"，二者都表现为带被打断。落地需叠加**时序**（衰减池 + 路露率 RER，见既有 `server/` 状态机）做最终确认。 |
| 夜晚 | 色彩阈值失效，分割退化；红/白锚点在夜间不可靠（另见 `night_lamp_report.md`）。 |
| 远端/背景 | 带远端与植被、阴影交界处偶发 `intra` 候选，需结合距离/时序过滤。 |
| 尺度先验 | `min_gap/max_gap` 需按场景水马尺寸标定；场景尺度变化需重校。 |

## 7. 运行方式

```bash
# 端到端：抓一帧实时流 + 跑分割/检测，输出标注图
python water_barrier/research/run.py --rtsp

# 跑指定帧（含标注截图）
python water_barrier/research/run.py data/input/1749_1333.png data/input/1749_0944.png

# 核心模块
python -c "from water_barrier.research import segment, detect"
```

产物：`research/out/`（无参数时的标注图）、`docs/img/`（本报告引用图）。需要
`python + opencv-python + numpy`。
