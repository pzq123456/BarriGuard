# BarriGuard 水马缺口检测算法报告

日期：2026-09-03　相机：1749（1920x1080 RTSP）　代码：`server/`（分割）+ `lab/gap_detector.py`（缺口判定）

## 1. 系统能做什么

```
RTSP 拉流 ──> 水马二值分割 ──> Slot 覆盖率快检 ──> 衰减池状态机 ──> 告警
   (server/)      (红∪白色阈)      (相对基准阈值)     (RER确认+闭锁+升级)
```

| 能力 | 说明 | 实测依据 |
|---|---|---|
| 水马二值分割 | 红∪白颜色阈值 × ROI × 形态学，输出 0/255 mask | GT 精度 P=0.95-0.97，R=0.91-0.92，IoU=0.87-0.88 |
| 整块缺损告警 | 基准态 slot 差分，缺口暴露为 mask 空洞 | 真实缺口（现场确实缺一块）两帧均稳定暴露 66-75px |
| 抗过车/行人遮挡 | 衰减池（0.5s/s 退化）+ RER 路露率确认 | 实流 90s：行人/过车致 0.53-0.62 覆盖率低谷，0 误报 |
| 告警闭锁 | ALARM 确认后不被瞬态降级，持续恢复 ~20s 才解除 | 实流：ALARM 从 36.7s 保持到 90s，期间覆盖率多次冲高 0.82 |
| 升级兜底 | RER 不达标的可疑持续 300s 后升级为 ALARM | 缺口视野半在深阴影时快门不达标，由升级路径兜底 |

实流端到端时延：缺口出现 → ALARM 约 10-70s（随缺口视野过车频率波动）。

## 2. 关键实测结论

- 真实缺口在 mask 中空洞宽 66-75px，两帧（09:44 / 13:33）一致；20px 级局部破损会被形态学闭运算回填（不可检），≥40px 才可检
- 最小可检缺损由 KNIT 核决定：检测分支不用大核后极限约 10px
- RER（路露率）实测分离度：非路内容 ≤0.10（货车 0.00、完好 slot 边缘 0.02-0.10）vs 真缺口 0.27-0.65，阈值 0.25
- 实时帧率 8.8-13.7 fps（1920x1080），状态机按 wall-clock 计时，帧率波动不影响时延语义

## 3. 注意事项（生产前必读）

1. **昼夜漂移是 P0**：17:35（未入夜）远端带覆盖率已从 0.33 塌陷到 0.14，FAR slot 会卡死 SUSPECTED 并在 300s 后误报。必须落地 LightMode 分支基线（白天/夜间各一套基准与阈值）
2. **阈值只在两帧上验证**（09:44 / 13:33），θ_RER=0.25 与路色模型需补正午逆光、傍晚侧光、夜间时段压测
3. **slot 基准覆盖率必须逐 slot 标定**：远端常态仅 0.21-0.75，全局阈值会常态误报（已改相对阈值 θ_k=0.5×base_k，但 base_k 要随光照模式更新）
4. **连通域计数判"未闭合"不可用**：缺口后方水马会把拓扑接回去，实测缺口存在时左排仍是单一连通域；只能用 slot 差分
5. **外观无法区分"停靠遮挡"与"真缺损"**：停放 >300s 的车会升级成告警（有界代价，人工复核消化）
6. 缺口视野过车频繁时告警延迟向 70s 端漂移，告警文案需标注
7. 闭运算核是为"连成整带"调的；如需检测裂缝/半倒，检测分支不得使用 KNIT 大核
8. 相机像素对齐：slot 差分在 16px 级网格上天然抗 5-10px 风抖，但相机大角度位移需重建基准
